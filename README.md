# PWGood Hat for Geoguessr Chrome Extension
 Расширение для браузера, которое заменяет кепку из геогессера на шляпу Пугода.
 
 Вся логика находится в файлах _manifest.json_ и _rules.json_.

 Запрос на спрайт кепки перехватывается и подсовывается мой спрайт, который залит на сервере ВК. 
 
 Вы можете поменять на свой спрайт, залив его на сторонний сервер (со своего компа не получится, нужно заливать) и вставив на него ссылку в _rules.json_. Как пример можно использовать спрайты из проекта, там есть оригинальный спрайт кепки и моя шляпа.
 ![image](https://github.com/user-attachments/assets/391b9124-f73c-477a-b503-ada9ad6cc884)

 Запрос на модель кепки также перехватывается и меняется на модель шляпы с сервера самого геогессера.
